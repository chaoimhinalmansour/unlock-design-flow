# UNLOCK 教学流程

按校内两节课安排查看 Book 1 至 5 的 LS 和 RW。每节课先学本节 WORDLIST 词汇，再进入教材任务。词条随对应原题练习，另有课首短练覆盖需要单独练习的词。第一节课末核对本节，第二节课末核对本单元。任务 GLOSSARY 在对应活动前查阅，固定听写沿用本分册 WORDLIST。

在单元页切换「校内两节课」和「原书顺序」。点词条可查看原书页码、本单元的教材位置和逐词短练习。公开网页用教材页码定位，原书全文和图片可查阅自己的教材。词汇安排用于备课和核对覆盖。

直接打开 `index.html`，或通过 GitHub Pages 打开网页。页面使用静态 HTML、CSS 和 JavaScript。
